# Instruções Codex

Este repositório contém uma migração compatível com Codex, mantendo intactos os materiais originais.

- Skills do projeto: `.agents/skills/`
- Agentes personalizados: `.codex/agents/`
- Instruções originais do Claude continuam apenas como referência histórica.

Ao executar tarefas, preserve a intenção do usuário, use a stack real do projeto e carregue somente o agente ou a skill pertinente. Não presuma autorização para publicar, enviar, excluir ou usar credenciais. Para domínios regulados, valide informações atuais em fontes oficiais e exija revisão profissional.
